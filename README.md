# spring-mcp-gateway

A Spring Boot MCP gateway in front of an existing FastAPI retrieval-augmented generation (RAG) service.

This repository currently contains the JUA-48 application scaffold.

## Technology stack

- Java 25
- Spring Boot 4.1.1
- Spring AI 2.0.1
- Maven 3.9.16 via the Maven Wrapper

Spring AI dependency versions are managed through the imported Spring AI BOM.
